# vite-test
학부 2학년 2학기 과정 중 과제로 만들었던 **vi**rtual **t**ext **e**ditor - vite

Windows / macOS / Ubuntu 등 운영체제 3개에서 모두 작동

## 개선해야 할 것들
1. 탐색 기능 추가 필요
2. 한 줄이 가로로 엄청 길면 커서 이동이 많이 오래 걸림
3. 탭(Horizontal Tab, \\t) 문자에 대한 커서 위치와 시각적 위치 사이의 괴리

## 실행 방법
리눅스 환경 기준 (경고 메시지는 Visual Studio 자체 #pragma 관련 경고이므로 무시해도 됨)
```bash
make
./vite
```
